## Executive Summary

Net-AV is pleased to submit this proposal to replace the end-of-life SIPRNet AV endpoints at Fort Belvoir RNEC-NCR. The inspection on August 27, 2024 identified Category I findings related to EOL Cisco SX20 and SX80 endpoints. Our solution addresses the critical security requirements while ensuring continued mission support for SIPRNet 365, S-CUB, S-DNR, and other classified communications.

The proposed system will improve efficiency, deliver premier AV/TEAMS/GVS support, and maintain backward interoperability with existing systems. Our turnkey solution includes all necessary equipment, installation, testing, commissioning, and training to ensure a seamless transition.

## Statement of Work

### Scope Overview

Net-AV will provide and install a complete videoconferencing solution to replace the EOL Cisco SX20 and SX80 endpoints at the Fort Belvoir RNEC-NCR facility. The solution will include Cisco Room Bar Pro systems with all necessary accessories, mounting hardware, cabling, and support services.

### Installation & Implementation

1. **Pre-Installation Phase**
   - Conduct detailed site survey
   - Verify network requirements and connectivity
   - Develop implementation plan with security protocols
   - Coordinate schedule with facility security personnel

2. **Installation Phase**
   - Remove existing Cisco SX20 and SX80 endpoints
   - Install new Cisco Room Bar Pro systems
   - Install control interfaces and peripherals
   - Configure network settings for SIPRNet compliance
   - Setup integration with TEAMS/GVS systems

3. **Testing & Commissioning Phase**
   - Verify system functionality
   - Test connectivity with required services (SIPRNet 365, S-CUB, S-DNR)
   - Validate interoperability with existing systems
   - Ensure compliance with DISA security requirements
   - Document system configuration and settings

4. **Training & Handover Phase**
   - Provide comprehensive user training
   - Deliver system documentation and user guides
   - Conduct knowledge transfer to technical staff
   - Verify customer acceptance criteria
